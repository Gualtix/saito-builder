# Landing Page / Homepage Style Taxonomy

*A reference for classifying, analyzing, benchmarking, and discovering landing page and homepage designs, written from a UX/UI and Interaction Design (IxD) perspective.*

Any page can be described along five independent axes: what it is built to do, which industry it serves, how it looks, how it behaves, and a few cross-cutting settings. Keeping the axes separate makes classifications consistent and comparable.

> **Note on terminology.** Category and style names follow terms widely used in web design practice. Grouping them into axes is a convention of this document, not a formal industry standard.

## The Classification Model

| Axis | Question it answers | Example values |
|---|---|---|
| **Page Type** | What job does the page do structurally? | Homepage, Sales Page (Long-Form), Lead-Generation Page |
| **Business Category** | Which industry goals and conventions apply? | SaaS / Software, Restaurant, Café & Food |
| **Visual Style** | How does it look and feel? | Minimalist, Brutalist / Neo-Brutalist, Glassmorphism |
| **Modifiers** | Which cross-cutting settings apply? | Dark, Dense, Rich motion |
| **Interaction Patterns** | How does it behave? | Sticky CTA, Scrollytelling |

### Classification rules

1. Classify each axis independently. Each one answers a different question.
2. Pick **one** Page Type and **one** Business Category, choosing the one whose goals and conventions dominate.
3. Pick **one** primary Visual Style and at most **one** secondary style.
4. Record all three Modifiers, then list up to four prominent Interaction Patterns.
5. Use names exactly as written in this document.
6. When two values seem to fit, check the **Often confused with** columns.

### Classification format

```text
Page Type:            Homepage
Business Category:    SaaS / Software
Visual Style:         Modern Clean (primary) + Bento Grid (secondary)
Modifiers:            Light · Balanced · Subtle
Interaction Patterns: Interactive Product Demo, Sticky CTA, Micro-Interactions
```

## 1. Page Types

The structural job of the page, defined by its primary conversion goal. Names follow common marketing terminology.

| Page Type | Purpose | Defining structure | Primary conversion | Typical use |
|---|---|---|---|---|
| Homepage | Orient multiple audiences and route them deeper | Full navigation, hero, summary sections, footer sitemap | Click into key sections | Any multi-page website |
| One-Page Site | Present a small business or offer on one scrolling page | Anchor-link navigation, stacked sections, contact at the end | Contact or visit | Small businesses, freelancers, simple products |
| Lead-Generation Page | Capture contact details in exchange for an offer | Form above the fold, little or no navigation, benefit bullets | Form submission | B2B, services, gated content |
| Click-Through Page | Warm visitors up before sending them to signup or checkout | Benefit-led sections, one repeated CTA button, no form | Click to next step | SaaS trials, promotions |
| Sales Page (Long-Form) | Persuade visitors to buy a single offer | Problem → solution → proof → offer → FAQ, repeated CTAs | Purchase | Courses, info products, single products |
| Squeeze / Waitlist Page | Collect an email address with minimal friction | Headline, one-field form, almost nothing else | Email signup | Pre-launch products, newsletters |
| Splash Page | Gate or route visitors before the main site | Full-screen message or choice | Choice made (age, region, language) | Alcohol brands, multi-region sites |
| App Download Page | Drive app installs | Device mockups, feature highlights, store badges, QR code | Install | Mobile apps |
| Event / Webinar Registration | Fill seats for a dated event | Date and venue up front, agenda, speakers, ticket tiers | Registration | Conferences, webinars, launches |
| Storefront Homepage | Start product browsing and buying | Category navigation, product grids, promotions, search, cart | Add to cart | Online retail |
| Search-First Homepage | Get users into results quickly | Prominent search bar, filters, category tiles, listings | Search performed | Marketplaces, directories, real estate, travel |
| Content Hub | Drive reading, discovery, and return visits | Lead story, topic sections, article cards, subscribe prompt | Read or subscribe | Publishers, blogs, resource centers |
| Portfolio / Showcase | Prove skill through selected work | Work grid or case-study sequence, short bio, contact | Inquiry | Designers, agencies, photographers |
| Campaign Microsite | Support one time-bound campaign as a standalone experience | Branding distinct from the main site, single immersive story | Campaign-specific (enter, share, buy) | Product launches, brand campaigns |

## 2. Business Categories

The industry or business model the page serves. Each category brings its own audience expectations and must-have content.

### 2.1 Purpose and audience

| Category | Purpose | Target audience | Design philosophy | Typical use cases |
|---|---|---|---|---|
| Corporate / Enterprise | Establish credibility with buyers, investors, and talent | Executives, procurement, investors, job seekers | Authority and stability over novelty | Large companies, B2B groups |
| SaaS / Software | Drive trials, demos, or signups | Business users, technical evaluators, buyers | Show the product; make value and pricing obvious | B2B/B2C software, developer tools, AI products |
| Tech Startup | Communicate a new idea and build early momentum | Early adopters, investors, press, recruits | Vision and momentum over completeness | Early-stage companies, new product categories |
| E-commerce / Retail | Sell many products efficiently | Consumers comparing and buying | Fast browsing, clear prices, low-friction checkout | Online stores, D2C brands, retailers |

| Creative Agency / Studio | Win clients by demonstrating creative ability | Brand and marketing decision-makers | The site itself is the portfolio piece | Design, branding, advertising, digital studios |
| Professional Services | Generate consultations through expertise | People or businesses with a specific problem | Expertise and approachability; people sell the service | Law, accounting, consulting, architecture |

| Education & E-learning | Enroll learners | Students, professionals, parents, institutions | Clear outcomes and credible instruction | Universities, course platforms, bootcamps |

| Entertainment & Gaming | Build hype and drive purchases, tickets, or streams | Fans and players | Immersion and spectacle | Game studios, film, music, venues |

## 3. Visual Styles

The look and feel. Any style can be paired with any Business Category, though some pairings are more common.

### 3.1 Definitions

| Style | Definition | Design philosophy | Typical use cases |
|---|---|---|---|
| Minimalist | Strips the page to essential content using whitespace and few elements | Less is more; every element must earn its place | Premium products, portfolios, design-led brands |
| Modern Clean | Tidy, contemporary layout that organizes plenty of content into clear sections | Clarity and scannability at scale | SaaS, professional services, corporate |
| Swiss / International Typographic | Grid- and type-driven style rooted in mid-20th-century Swiss graphic design | Objective communication through grid and type | Design studios, architecture, cultural institutions |
| Bold & Vibrant | High-energy style with saturated colors and oversized type | Grab attention and project confidence | Consumer brands, startups, campaigns |
| Maximalist | Deliberately dense, layered mix of colors, patterns, fonts, and images | More is more; abundance as personality | Fashion, music, art, youth brands |
| Brutalist / Neo-Brutalist | Brutalist: raw, default-looking web aesthetics. Neo-Brutalist: flat bright blocks, thick outlines, hard shadows | Honesty and rebellion against polished templates | Creative studios, indie products, developer tools |
| Flat / Material | Two-dimensional UI of solid colors and simple shapes; Material adds subtle elevation | Digital-native clarity | Apps, consumer services |
| Glassmorphism | Translucent, frosted-glass panels over colorful backgrounds | Depth and layering with a light, modern feel | Fintech, AI products, OS-inspired interfaces |
| Neumorphism | Soft, extruded shapes made with paired light and dark shadows on a same-color surface | Tactile softness | Concept designs, small widgets; rare on full homepages |
| Gradient / Aurora | Large, soft mesh gradients as the main visual element | Modern atmosphere without imagery | SaaS, AI, fintech, startups |
| Bento Grid | Rounded tiles of varied sizes, each holding one feature or message | Many ideas, digestible at a glance | Feature overviews, consumer tech, SaaS |
| Editorial | Magazine-inspired layout led by typography and photography | Content and storytelling first | Publishers, brand journals, cultural institutions |
| Luxury / Elegant | Restrained, refined style that signals exclusivity | Restraint and craft signal value | Luxury goods, high-end hotels, fine dining |
| Photo-Led / Cinematic | Full-bleed photography or video carries the page | Show, don't tell | Hospitality, travel, restaurants, real estate |
| Retro / Vintage | Evokes a past era through color, type, and texture | Nostalgia, heritage, authenticity | Cafés, barbershops, craft beverages, heritage brands |
| Organic / Natural | Nature-inspired style with earthy colors and soft, irregular shapes | Calm, health, sustainability | Wellness, food, sustainability, beauty |
| Illustrated | Custom illustration is the primary visual language | Explain and humanize through drawing | Startups, education, fintech, children's brands |
| Playful / Friendly | Rounded shapes, cheerful colors, and a casual tone | Delight and low intimidation | Consumer apps, family brands, education |
| 3D / Immersive | Rendered or real-time 3D objects and scenes create depth | Spectacle and product realism | Product launches, consumer tech, automotive |
| Futuristic / Cyberpunk | Sci-fi aesthetic with neon accents on dark backgrounds | Signal cutting-edge technology | AI, Web3, gaming, cybersecurity |
| Technical / Utilitarian | Function-first style that exposes structure, specs, and code | Precision and engineering credibility | Developer tools, engineering, infrastructure |
| Data-Centric | Charts, metrics, and dashboard visuals are the hero content | Prove value with numbers | Analytics, B2B SaaS, finance, research |

### 3.2 Distinguishing elements

| Style | Key visual elements | Interaction tendencies | Watch-outs | Often confused with |
|---|---|---|---|---|
| Minimalist | Large whitespace, 1–2 colors, few sections, strong type | Subtle transitions, little motion | Hidden navigation; low-contrast gray text | Modern Clean |
| Modern Clean | Light backgrounds, sans-serif type, card grids, one accent color | Hover states, light scroll reveals | Can look generic or template-made | Minimalist, Flat / Material |
| Swiss / International Typographic | Strict grid, large sans-serif type, asymmetry, flat color | Restrained; typographic hover effects | Oversized type breaking on small screens | Minimalist, Brutalist / Neo-Brutalist |
| Bold & Vibrant | Saturated palette, oversized headlines, color-blocked sections | Animated type, energetic transitions | Contrast on saturated backgrounds; visual fatigue | Maximalist, Playful / Friendly |
| Maximalist | Layered collage, clashing patterns, many typefaces | Rich motion, playful hovers | Readability, unclear hierarchy, page weight | Bold & Vibrant |
| Brutalist / Neo-Brutalist | Visible borders, system or monospace fonts, hard shadows, flat blocks | Abrupt state changes, little easing | Can read as broken to mainstream audiences | Swiss / International Typographic |
| Flat / Material | Solid colors, simple icons, cards, minimal shadows | Press feedback, standard transitions | Flat buttons with weak affordance | Modern Clean |
| Glassmorphism | Background blur, transparency, thin light borders, vivid backdrop | Hover glow, layered parallax | Text contrast over shifting backgrounds; blur cost on low-end devices | Gradient / Aurora |
| Neumorphism | Monochrome surface, paired soft shadows, rounded shapes | Pressed and raised states | Low contrast often fails WCAG; weak affordance | Flat / Material |
| Gradient / Aurora | Mesh or blurred gradients, glow, clean type | Animated or cursor-reactive gradients | Overused; text contrast on gradients | Glassmorphism, Futuristic / Cyberpunk |
| Bento Grid | Modular rounded tiles of varied sizes, mixed media per tile | Tile hovers, small in-tile animations | Tile order on mobile; too many tiles dilute focus | Modern Clean (uniform card grids) |
| Editorial | Serif display type, multi-column grid, pull quotes, large images | Long-scroll reading, subtle reveals | Long line lengths; type scale on mobile | Luxury / Elegant |
| Luxury / Elegant | Neutral or black palette, metallic accents, high-contrast serif, full-bleed photos | Slow fades, smooth transitions, video | Thin light type; hidden prices or info | Minimalist, Editorial |
| Photo-Led / Cinematic | Full-screen images or video, overlay text, minimal chrome | Background video, galleries, parallax | Page weight and slow loading; text over images | Luxury / Elegant |
| Retro / Vintage | Era-specific palette, serif, script, or slab type, badges, grain | Usually low motion | Decorative fonts hurt legibility; can feel dated | Organic / Natural |
| Organic / Natural | Earth tones, natural textures, blob shapes, nature imagery | Gentle, slow motion | Low-contrast earthy palettes | Retro / Vintage |
| Illustrated | Consistent custom illustration system, characters, spot art | Animated illustrations | Mixed illustration styles; animation file size | Playful / Friendly |
| Playful / Friendly | Rounded corners, bright or pastel palette, rounded fonts, mascots | Bouncy micro-interactions | Can undermine trust for serious services | Illustrated, Bold & Vibrant |
| 3D / Immersive | 3D renders or WebGL scenes, lighting, depth | Scroll-driven 3D, rotation, cursor-reactive scenes | Heavy performance cost; motion sickness; needs fallbacks | Futuristic / Cyberpunk |
| Futuristic / Cyberpunk | Dark base, neon accents, glow, glitch effects, tech type | Glitch transitions, terminal-like effects | Readability; flashing effects (seizure risk) | Gradient / Aurora |
| Technical / Utilitarian | Monospace accents, visible grid lines, diagrams, code blocks | Copy-code buttons, tabs, little motion | Feels cold or impenetrable to non-experts | Data-Centric, Brutalist / Neo-Brutalist |
| Data-Centric | Charts, KPI tiles, dashboard screenshots | Animated counters, interactive charts | Decorative or unreadable charts; color-only encoding | Technical / Utilitarian |

## 4. Modifiers

Cross-cutting settings that apply on top of any Visual Style.

| Modifier | Values | Notes |
|---|---|---|
| Color mode | Light · Dark · Dual | Dark is a mode any style can use, not a style. "Dual" means the user can switch. |
| Density | Sparse · Balanced · Dense | How much content appears per screen. |
| Motion level | Static · Subtle · Rich | Rich motion must still respect the user's reduced-motion setting. |

## 5. Interaction Patterns

Recurring behaviors that shape how visitors experience and act on a page.

| Pattern | Definition | Purpose | Common in | Watch-outs |
|---|---|---|---|---|
| Sticky CTA | A CTA button or bar that stays visible while scrolling | Keep the main action one tap away | SaaS, local services, mobile commerce | Must not cover content |
| Mega-Menu | Large dropdown showing many navigation links at once | Navigate large sites | Corporate, retail, universities | Hover-only menus fail touch and keyboard users |
| Scroll-Triggered Reveal | Elements animate in as they enter the screen | Pace content and add polish | Most modern styles | Overuse delays content |
| Scrollytelling | Scrolling drives a sequenced story or animation | Tell a product or data story step by step | Product launches, campaigns, journalism | Hijacked scrolling frustrates users |
| Parallax | Layers move at different speeds while scrolling | Create depth | Hospitality, agencies, campaigns | Motion sickness; mobile performance |
| Kinetic Typography | Animated text as a primary visual | Make the message memorable | Agencies, campaigns, startups | Readability while moving |
| Micro-Interactions | Brief feedback animations on hover, click, or input | Confirm actions and add delight | All categories | Keep them short and purposeful |
| Background Video Hero | Looping muted video behind the hero | Convey atmosphere instantly | Hospitality, entertainment, fitness | Page weight; needs a pause control |
| Interactive Product Demo | Clickable or animated product walkthrough on the page | Let visitors try before signing up | SaaS, fintech | Keep it short; allow skipping |
| Calculator / Configurator | Tool that computes a price or saving, or builds a custom product | Personalize the value | Finance, real estate, automotive, SaaS pricing | State assumptions clearly |
| Search & Faceted Filtering | Search with filters to refine results | Fast discovery in large inventories | Retail, marketplaces, real estate, travel | Filter usability on mobile |
| Carousel / Slider | Rotating slides in one space | Show several messages in one spot | Retail promotions, galleries | Later slides get little attention; auto-rotation hurts accessibility |
| Multi-Step Form | Form split into short steps with progress shown | Reduce perceived effort | Lead generation, quotes, applications | Show progress; keep entered data |
| Booking / Date Picker Widget | Inline availability and booking tool | Convert intent immediately | Hospitality, healthcare, fitness, restaurants | Third-party widgets may be inaccessible |
| Click-to-Call / Directions | Tappable phone and map links | Turn mobile visits into calls and visits | Local services, restaurants, healthcare | Phone number must be visible on mobile |
| Countdown / Urgency Timer | Live timer to a real deadline | Create urgency | Events, sales, launches | Fake or resetting timers are a recognized dark pattern |
| Exit-Intent / Modal Popup | Overlay triggered by time, scroll, or attempt to leave | Capture leaving visitors | Retail, publishing, lead generation | Intrusive on mobile; can hurt search ranking |
| Chat / Assistant Widget | Live chat or chatbot launcher | Answer questions in context | SaaS, retail, services | Covers content on mobile; adds page weight |
| Custom Cursor & Page Transitions | Replaced cursor and animated page changes | Signal creative craft | Agencies, portfolios | Can hinder usability and accessibility |

## 7. Quality Baseline

These apply to every classification and make benchmarks comparable.

- **Accessibility (WCAG 2.2 AA):** text contrast of at least 4.5:1 (3:1 for large text), visible keyboard focus, touch targets of at least 24×24 CSS px, a pause control for motion that plays longer than 5 seconds, and respect for the reduced-motion setting.
- **Performance (Core Web Vitals, "good" thresholds):** Largest Contentful Paint ≤ 2.5 s, Interaction to Next Paint ≤ 200 ms, Cumulative Layout Shift ≤ 0.1.
- **Mobile-first:** the primary CTA and key information are reachable on a small screen without hunting.
- **Focus:** one primary conversion goal per page, matching its Page Type.

## 8. Glossary

| Term | Meaning |
|---|---|
| Above the fold | The part of a page visible on load, before scrolling. |
| Affordance | A visual cue that shows how an element can be used, such as a button looking clickable. |
| CTA (Call to Action) | The prompt for the page's main action, usually a button. |
| Conversion | The goal action a page exists for, such as a purchase, signup, or call. |
| Core Web Vitals | Google's user-experience metrics for loading (LCP), responsiveness (INP), and visual stability (CLS). |
| Dark pattern | A design that tricks users into actions they did not intend. |
| Full-bleed | An image or section that extends to the edges of the screen. |
| Hero | The first and most prominent section of a page. |
| Social proof | Evidence that others trust the offer: reviews, client logos, testimonials, user counts. |
| Trust signals | Elements that reduce perceived risk: certifications, guarantees, security badges, real contact details. |
| WCAG | Web Content Accessibility Guidelines, the W3C standard for web accessibility. |
